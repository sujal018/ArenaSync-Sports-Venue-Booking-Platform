# 🏟️ ArenaSync – Sports Venue Booking Platform

ArenaSync is a full-stack sports venue booking platform that enables customers to discover and book sports venues while allowing turf owners to manage their facilities and administrators to oversee the entire platform. The system provides secure authentication, real-time slot availability, online payment processing, and role-based access control for a seamless booking experience.

## 🚀 Features

- 🔐 JWT-based Authentication & Authorization
- 👥 Role-Based Access (Admin, Turf Owner, Customer)
- 🏟️ Turf Registration & Management
- 📅 Day-wise Slot Generation
- ⚡ Real-Time Slot Availability
- 💳 Razorpay Payment Integration
- 💰 Dynamic Pricing & Platform Commission
- ⭐ Customer Reviews & Ratings
- 📊 Booking History & Revenue Dashboard
- ⏳ Automatic Cleanup of Unpaid Bookings
- 📱 Responsive React UI
